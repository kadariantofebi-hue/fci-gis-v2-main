## API Service (Phase 2)

### 2.1 Tambah `projectGeoJson()` ke `services/api/projects.ts`

```ts
export async function projectGeoJson() {
  if (apiMode === 'real') return realFetch('/projects/geojson');
  // Build FeatureCollection dari projects
  const features = projects
    .filter(p => p.geometry != null)
    .map(p => ({
      type: 'Feature' as const,
      geometry: p.geometry!,
      properties: {
        id: p.id,
        projectCode: p.projectCode,
        projectName: p.projectName,
        status: p.status,
        fiscalYear: p.fiscalYear,
        jenisInfrastruktur: p.jenisInfrastruktur,
        opdName: p.opdName
      }
    }));
  return ok(
    { type: 'FeatureCollection', features },
    'Project GeoJSON',
    { path: '/api/v1/projects/geojson', count: features.length }
  );
}
```

### 2.2 Tambah `projectDashboardStats()` ke `services/api/projects.ts`

```ts
export async function projectDashboardStats() {
  if (apiMode === 'real') return realFetch('/projects/dashboard-stats');
  const total = projects.length;
  const berjalan = projects.filter(p => p.status === 'in_progress').length;
  return ok(
    { totalProyek: total, proyekBerjalan: berjalan },
    'Project dashboard stats',
    { path: '/api/v1/projects/dashboard-stats' }
  );
}
```

Decision: PRD §8.1 KPI: hanya Total Proyek + Proyek Berjalan. Fungsi ini menjadi single source of truth. `dashboardStats()` (di `services/api/assets.ts`) tetap ada tapi tidak dipanggil dari Dashboard lagi.

## Risks

1. **Mock project geometry** — koordinat arbitrary mungkin tidak representatif secara geografis untuk Kabupaten Sidoarjo. Acceptable untuk v1.4 mock; production butuh data real.
2. **MapContainer generalization** — risk of breaking existing asset mode usage di asset detail/create page. Mitigasi: keep asset mode path unchanged, default mode='project' di Dashboard.
3. **Status color palette overlap dengan asset colors** — proyek "berjalan" (amber) bisa mirip dengan asset "jalan" (amber). Mitigasi: Legend eksplisit + mungkin beda shade.
4. **E2E selector break** — existing tests pakai `stat-card-*` selectors. Mitigasi: update E2E bersamaan dengan FE changes.
5. **vitest mock reset** — perubahan di `mocks/projects.ts` bisa affect tests yang import mock array langsung (tidak via service). Mitigasi: search & verify sebelum commit.
6. **Subagent tool budget** — saya kerjakan sebagai orchestrator langsung (bukan delegate_task) untuk hindari max_iterations pitfall yang sudah verified 2026-06-12.
